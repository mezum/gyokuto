# 字句仕様

ソースコードは UTF-8 で与えられ、先頭から最長一致でトークンに分割する。

## 位置 (Span)

- 各トークンはソース上のバイトオフセットの半開区間 `[start, end)` を持つ
- エラーも同じ形式の位置を持つ

## 空白

- Unicode の `Pattern_White_Space` に属する文字を空白とし、読み飛ばす
- 空白はトークンの区切りとしてのみ意味を持つ

## コメント

- コメントは空白と同じく読み飛ばし、トークンの区切りとしてのみ意味を持つ
- 行コメントは `//` から LF の直前まで
- ブロックコメントは `/*` から対応する `*/` まで
  - ネストでき、内側の `/*` と `*/` の対応を数えて終端を決める (`/* a /* b */ c */` は 1 つのコメント)
  - 閉じていないブロックコメントはエラーとする
- ドキュメントコメント (`///`、`//!`、`/** */`、`/*! */`) も通常のコメントとして扱う

## 識別子

- `XID_Start` または `_` で始まり、`XID_Continue` が 0 文字以上続くもの
  - ただし `_` 単体は識別子ではなく、後述の `_` トークン となる
- キーワードと一致するものは識別子ではなくキーワードとなる
- Unicode 正規化は行わず、バイト列として比較する
- raw identifier (`r#foo`) はサポートしない

## `_` トークン

- `_` 単体はワイルドカードを表す専用のトークンとする

## 数値リテラル

整数リテラル

- 10 進数は `0`〜`9` で始まる
- 16 進数は `0x`、8 進数は `0o`、2 進数は `0b` を接頭辞とする (小文字のみ)
  - 接頭辞の後には 1 つ以上の数字が必要
- 数字の間や末尾に `_` を置ける (`1_000`、`0xff_ff`)
- 以下の型サフィックスを付けられる
  - `i8` `i16` `i32` `i64` `isize`
  - `u8` `u16` `u32` `u64` `usize`

浮動小数点リテラル

- 10 進数のみ
- 小数部を持つ場合、小数点の両側に数字が必要 (`1.0`)
  - `1.` は整数 `1` と `.` の 2 トークンになる
- 指数部は `e` / `E` に続く省略可能な符号 `+` / `-` と数字 (`1e10`、`2.5E-3`)
- 以下の型サフィックスを付けられる
  - `f32` `f64`
- 小数部と指数部を持たない 10 進数に `f32` / `f64` を付けたものも浮動小数点リテラルとする (`1f32`)

共通

- `-` は演算子であり、リテラルには含まない
- リテラルの直後に続く `XID_Continue` の文字はサフィックスとして扱い、有効なサフィックスでなければエラーとする
  - 例: `1u7`、`1abc`、`0b12`、`0x`、`1e`
- 値の範囲は字句解析では検査せず、型検査で行う
- `t.0.1` のようなフィールドアクセスの文脈に浮動小数点リテラルが現れた場合は、構文解析で分割する

## 文字・文字列リテラル

文字リテラル

- `'` で囲んだ 1 文字、または 1 つのエスケープシーケンス
- 値は Unicode スカラー値 (`char` 型)
- `'`・`\`・改行 (LF / CR)・タブはエスケープせずに書けない
- 空 (`''`) や 2 文字以上はエラーとする

文字列リテラル

- `"` で囲んだ 0 文字以上の文字またはエスケープシーケンス
- `"` と `\` 以外の文字は、改行も含めてそのまま書ける
- 改行の CRLF は値としては LF に正規化する。単独の CR はエラーとする
- 行継続: `\` の直後に改行が続く場合、その改行と後続の空白 (`Pattern_White_Space`) を値に含めない

エスケープシーケンス

- `\n` `\r` `\t` `\\` `\0` `\'` `\"`
- `\x` に続く 2 桁の 16 進数 (`00`〜`7F`)
- `\u{` `}` で囲んだ 1〜6 桁の 16 進数 (`_` 区切り可)
  - 値は Unicode スカラー値 (`0`〜`10FFFF`、サロゲート `D800`〜`DFFF` を除く) でなければならない
- 上記以外の `\` で始まる並びはエラーとする

共通

- 閉じていないリテラルはエラーとする
- リテラルの直後に `XID_Continue` の文字が続く場合はエラーとする
  - サフィックスは将来の拡張のために予約し、現時点ではエラーとする

## バイト文字・バイト文字列リテラル

文字・文字列リテラルに接頭辞 `b` を付けたもの。以下の差分を除き、文字・文字列リテラルと同じ規則に従う。

バイト文字リテラル (`b'a'`)

- 値は `u8`
- エスケープせずに書ける文字は ASCII のみ
- `\x` は `00`〜`FF` を書ける
- `\u{...}` はエラーとする

バイト文字列リテラル (`b"abc"`)

- 値はバイト列
- ASCII 以外の文字も書け、UTF-8 でエンコードしたバイト列を値とする
- `\x` は `00`〜`FF` を書ける
- `\u{...}` は UTF-8 でエンコードしたバイト列を値とする

## raw 文字列リテラル

文字列・バイト文字列リテラルに接頭辞 `r` を付けたもの (`r"..."`、`br"..."`)。

- `r` と `"` の間に 0〜255 個の `#` を置ける (`r#"..."#`)
  - 開始と同じ数の `#` が `"` の後に続いた位置で終端となる
  - 256 個以上はエラーとする
- エスケープシーケンスは解釈せず、`\` も値にそのまま含める
- 改行の CRLF は値としては LF に正規化する。単独の CR はエラーとする
- raw バイト文字列は、バイト文字列と同じく UTF-8 でエンコードしたバイト列を値とする
- 閉じていないリテラルはエラーとする
- リテラルの直後に `XID_Continue` の文字が続く場合はエラーとする (サフィックスの予約は文字列リテラルと同じ)

## 演算子・区切り記号

- 最長一致で解釈する (`<<=` は `<<` と `=` ではなく 1 トークン)
- `Vec<Vec<T>>` の `>>` なども字句としては 1 トークンとし、型引数の文脈では構文解析で `>` 2 つに分割する

算術

- `+` 加算
- `-` 減算・符号反転
- `*` 乗算
- `/` 除算
- `%` 剰余

ビット演算・論理演算

- `&` ビット積・参照
- `|` ビット和・クロージャ引数の区切り・パターンの選択
- `^` 排他的論理和
- `!` 否定
- `<<` 左シフト
- `>>` 右シフト
- `&&` 論理積
- `||` 論理和

比較

- `==` 等価
- `!=` 非等価
- `<` 未満・型引数の開始
- `>` 超過・型引数の終了
- `<=` 以下
- `>=` 以上

代入

- `=` 代入
- `+=` `-=` `*=` `/=` `%=` 算術の複合代入
- `&=` `|=` `^=` `<<=` `>>=` ビット演算の複合代入

区切り記号

- `.` フィールド・メソッドアクセス
- `..` 半開区間・構造体更新
- `..=` 閉区間
- `::` パス区切り
- `:` 型注釈
- `;` 文の終端
- `,` 要素の区切り
- `->` 戻り値の型
- `=>` match のアーム
- `?` エラー伝播
- `#` 属性 (`#[...]`)
- `(` `)` `[` `]` `{` `}` 括弧

## エラー

- どのトークンにも当てはまらない文字は、その文字の位置を持つエラーとする
- エラー後も字句解析を続け、複数のエラーをまとめて報告できるようにする
